# 🔐 Password Strength Checker

A simple **C++ program** that checks the strength of a password based on different security conditions.

I created this project while learning C++ to practice strings, loops, conditions, and character checking.

## ✨ Features

The program checks whether a password contains:

- Uppercase letters (A-Z)
- Lowercase letters (a-z)
- Numbers (0-9)
- Special characters
- Minimum required length

Based on these conditions, the program tells the user how strong the password is.

## ▶️ How to Run

Compile the program:

```bash
g++ main.cpp -o password_checker
```

Run it:

**Windows**
```bash
password_checker.exe
```

**Linux / macOS**
```bash
./password_checker
```

## 💻 Example

```text
Enter your password: Hello@123

Password Strength: Strong
```
